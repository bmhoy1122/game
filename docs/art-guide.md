# 아트 가이드 — 규격 · 발주 프롬프트 · 시트 만드는 법

> 이 문서는 ChatGPT에 그림을 시킬 때의 발주서이자, 받은 그림을 게임에 넣는 절차서다.
> 코드 쪽 규격(행 순서·칸 크기)의 최종 정답은 `evening-night/index.html` 의
> `ART` / `MOBART` / `PROPART` 객체다. 어긋나면 그쪽을 믿을 것.

## 받은 그림을 시트로 만드는 절차

ChatGPT가 준 그림은 라벨과 마젠타 배경이 섞인 큰 이미지다. 다음 순서로 처리했다.

1. **키잉** — `G<75 && R>135 && B>125 && R-G>90 && B-G>80` 인 픽셀을 투명으로.
   (마젠타가 압축 때문에 순수 `#FF00FF` 가 아니라서 범위로 잡는다.)
2. **라벨 제거** — 연결 요소 중 높이 62px 미만이면서 흰색/노란색 비율이 55% 넘는 것.
3. **프레임 분할** — 행 투영 → 열 투영. 밴드 간격 6px, 열 간격 12~14px.
4. **크기 정규화** — 시트마다 캐릭터 키가 제각각이라(비눗방울 시트가 간지럼 시트보다 30% 컸다)
   시트별 프레임 높이 중앙값으로 배율을 맞춘다.
5. **앵커 정렬** — 각 프레임 아래 12% 영역의 x 무게중심을 발 위치로 보고 칸 가운데 아래에 붙인다.
6. **얼굴 분리** — 심통이 표정 시트는 머리 실루엣까지 들어 있다. 안쪽 타원 영역에서
   바탕색과 거리 95 이상인 픽셀만 남기면 눈·입·볼만 뽑힌다.
7. **축소·감색** — 96px 칸으로 줄이고 `FASTOCTREE` 160색. (1MB → 200KB)

**주의: `idle` 과 `walk` 만 왼쪽을 보고 온 적이 있다.** 코드는 전부 오른쪽 기준이다.
얼굴(살색)과 뒤통수(머리색)의 x 무게중심을 비교하면 방향을 기계적으로 판별할 수 있다.

## 0. 먼저 알아야 할 GPT 작업 원칙 5가지

이걸 안 지키면 몇 번을 다시 시켜도 시트가 안 맞습니다.

1. **설정화를 먼저 1장 만들고, 이후 모든 요청에 그 이미지를 첨부**하세요.
   설정화 = 정면·측면·후면 + 팔레트 칩(색 사각형 6개)이 한 장에 있는 그림.
2. **한 번에 한 동작(1행)만.** "6프레임 걷기" 정도가 한계입니다. 20행 통짜는 포기하세요.
3. **4배 크기로 받아서 줄이세요.** 96×96을 바로 달라고 하면 뭉개집니다.
   → 칸당 384×384로 받고, 나중에 96으로 축소.
4. **투명 배경은 GPT가 잘 못 합니다.** `배경은 순수 마젠타 #FF00FF 단색`으로 받아서
   나중에 색 제거하세요. (원하시면 제가 제거 스크립트 만들어 드립니다.)
5. **크기·위치 고정 문구를 매번 넣으세요.**
   `모든 프레임에서 캐릭터 키는 칸 높이의 85%, 머리 위 여백 8%, 발바닥은 칸 바닥선에 접함.
   프레임 사이에 캐릭터가 커지거나 작아지지 않게.`

## 2. 주인공 — 부위별 발주

### 2-1. 설정화 (제일 먼저, 1장)

```
[스타일 기준 문장]
캐릭터 설정화를 한 장 그려줘.
30대 어른, 편안한 카디건과 흰 셔츠, 헐렁한 바지, 부드러운 표정, 항상 살짝 웃고 있음.
같은 인물을 정면 / 오른쪽 측면 / 후면 3방향으로 나란히, 키 비율을 똑같이.
오른쪽 아래에 사용한 색 6개를 정사각형 칩으로 나열.
```

### 2-2. 기본 이동 (2회 요청)

| 요청 | 프레임 | 프롬프트 핵심 |
|---|---|---|
| idle | 4 | `숨쉬기. 어깨가 아주 조금 위아래로. 오른쪽을 바라봄` |
| walk | 6 | `걷기 한 바퀴. 1·4프레임이 접지, 3·6이 공중` |

> **오른쪽을 바라보는 방향만** 그리게 하세요. 왼쪽은 코드가 반전합니다.

### 2-3. 간지럼 (Z) — 3행

간지럼은 "때리는 그림"이 아니라 **손끝을 앞으로 내밀어 꼬물거리는 그림**입니다.
이게 폭력성 제거의 핵심이라 문장을 정확히 넣으세요.

```
[스타일 기준 문장] + [설정화 첨부]
같은 인물의 '간지럽히기' 동작 3프레임을 가로로 나란히.
주먹을 쥐지 말고 손가락 다섯 개를 펴서 꼬물거리며 앞으로 내미는 동작.
1: 팔을 살짝 뒤로 당겨 준비 / 2: 손가락을 앞으로 쭉 뻗어 꼬물 / 3: 손을 거둠.
표정은 장난스럽게 웃음. 절대 주먹이나 타격 자세가 아니어야 함.
```

- `tickle1` 3프레임 (짧게)
- `tickle2` 3프레임 (반대 손)
- `tickle3` 4프레임 (양손으로 크게, 몸을 앞으로 기울임)

### 2-4. 비눗방울 (X) — 2행

```
같은 인물이 '비눗방울 채를 입으로 부는' 동작 4프레임.
한 손에 동그란 비눗방울 채(고리 달린 막대)를 들고 입 앞에 가져와 볼을 부풀려 훅 부는 동작.
1: 채를 입으로 올림 / 2: 볼이 부풀어 오름 / 3: 훅 불며 볼이 홀쭉 / 4: 미소
비눗방울 자체는 그리지 말고 캐릭터만. 방울은 따로 발주함.
```

- `blow` 4프레임 (기본)
- `blowBig` 5프레임 (허리를 낮추고 크게 부는 동작, 커맨드 기술용)

### 2-5. 안아주기 (C) — 3행 ★ 중요

```
같은 인물의 '안아 올리기' 동작.
A) 팔을 넓게 벌려 껴안으려 다가가는 자세 3프레임
B) 품에 동그란 것을 안고 있는 정지 자세 2프레임 (품 안은 비워두고 팔로 원을 만듦)
C) 안은 것을 머리 위로 들어 빙글 돌려 위로 띄우는 동작 4프레임
   — 던지는 게 아니라 '위로 붕 띄워주는' 놀이 동작. 웃는 표정 필수.
```

- `hugReach` 3 / `hugHold` 2 / `hugToss` 4
- **품 안은 비워서** 그리게 하세요. 심통이는 코드가 그 자리에 올려줍니다.

## 3. 소품 — 손에 붙이는 별도 이미지 ★ 핵심 절약 지점

**소품마다 캐릭터 모션을 새로 그리면 안 됩니다.**
캐릭터는 위의 `carryIdle / carryWalk / carryUse` 3행만 있으면 되고,
소품은 **정지 그림 1~2장씩 따로** 받아서 코드가 손 위치에 붙입니다.

### 소품 4종 제안

| 소품 | 효과 | 필요한 그림 |
|---|---|---|
| **깃털** | 간지럼 사거리 2배, 여러 마리 동시 | 정지 1장 + 흔들림 2장 |
| **물뿌리개** | 앞으로 부채꼴 물줄기, 넓지만 약함 | 정지 1장 (물줄기는 이펙트로 따로) |
| **딸랑이** | 흔들면 주변 심통이가 3초간 춤춤 | 정지 1장 + 흔들림 2장 |
| **풍선** | 들고 있으면 점프가 두 배로 높아짐 | 정지 1장 + 살랑 2장 |

발주 프롬프트:

```
[스타일 기준 문장]
게임 아이템 아이콘 4개를 각각 별도 이미지로. 손잡이가 화면 아래를 향하도록,
캐릭터가 손에 쥐었을 때 자연스럽도록 그려줘. 캐릭터는 그리지 말고 물건만.
1) 알록달록한 큰 깃털
2) 노란 물뿌리개 (주둥이가 오른쪽)
3) 나무 손잡이 딸랑이 (동그란 방울 두 개)
4) 빨간 하트 풍선 (실이 아래로)
각 물건 크기는 어른 팔 길이의 3분의 1 정도 비율.
```

> 이 방식이면 소품 10개를 늘려도 캐릭터 그림은 하나도 안 늘어납니다.
> 소품을 놓아둘 자리(벤치·상자·평상)는 배경 소품으로 따로 받으세요.

## 4. 심통이 4종 — 얼굴 분리 방식 ★

몸 모션과 **표정을 따로** 받으세요. 표정만 바꿔 끼우면 웃음 3단계가 공짜로 생깁니다.

### 4-1. 몸 (종류별)

```
[스타일 기준 문장]
동그랗고 폭신한 생물 캐릭터. 몸통은 거의 완전한 원, 짧은 발 두 개, 팔은 없음.
얼굴은 비워두고 몸통만 그려줘 (눈·입 없이).
[먼지뭉치: 회보라색, 테두리가 솜뭉치처럼 삐죽삐죽]
[심통 고양이: 살구색, 삼각 귀 두 개와 짧은 꼬리]
[졸린 곰: 연갈색, 둥근 귀 두 개, 몸이 제일 큼]
[잠투정 대왕: 연하늘색, 아주 크고, 끝에 방울 달린 수면모자]
동작: idle 4프레임(숨쉬기), walk 6프레임(통통 튀며 걷기)
```

### 4-2. 표정 (종류별 1장, 4칸)

```
같은 생물의 얼굴 표정 4개를 가로로 나란히. 얼굴 부분만, 몸은 그리지 말고.
1) 삐죽 — 눈은 크고 동그랗고, 입은 아래로 휜 곡선, 눈썹 없음
2) 갸웃 — 한쪽 눈만 조금 작게, 입은 짧은 직선
3) 웃음 — 눈이 반달, 입이 큰 U자, 볼에 분홍 원
4) 활짝 — 눈이 ^^ 모양으로 감기고 입은 크게 벌린 웃음. 이빨은 그리지 말 것
```

### 4-3. 반응 모션 (여기가 이번 요청의 핵심)

| 이름 | 프레임 | 프롬프트 핵심 |
|---|---|---|
| `tickled` | 4 | `간지러워서 몸을 좌우로 비틀고 위아래로 들썩이는 동작. 몸이 물결처럼 휘어짐` |
| `bubbled` | 4 | `투명한 큰 비눗방울 안에 갇혀 둥실 떠오르는 동작. 방울 안에서 발이 허우적. 방울은 흐릿한 하늘색 반투명` |
| `held` | 2 | `누군가 품에 안아 들어올린 상태. 몸이 살짝 눌리고 발이 아래로 축 늘어짐. 표정은 활짝` |
| `dance` | 6 | `딸랑이 소리에 신나서 좌우로 스텝을 밟는 동작` |
| `poof` | 6 | `빙글빙글 돌다가 꽃과 반짝임으로 터지며 사라짐. 마지막 2프레임은 캐릭터 없이 꽃만` |

> **비눗방울에 맞으면 방울에 갇혀 둥실 뜬다** — 이 연출을 쓰면 "맞았다"가 완전히
> 사라지고 3살도 무슨 일이 일어났는지 즉시 압니다. `bubbled`는 꼭 받으세요.

## 6. 배경 — 장면 5개 × 3레이어 + 오브젝트

### 레이어 (가로로 이어붙여도 티 안 나게)

| 레이어 | 크기 | 스크롤 | 내용 |
|---|---|---|---|
| far | 1920×400 | 0.25배 | 하늘 + 먼 지형. 아래 40px은 잘려도 되게 여유 |
| mid | 1920×360 | 0.5배 | 건물·나무. **아래쪽 40px 투명** |
| near | 1920×240 | 0.8배 | 앞쪽 소품. **아래쪽 절반 투명** |

**바닥(지평선 아래)은 코드가 그립니다.** 화면상 지평선은 y=362이고
바닥은 y=362~540. near 레이어 하단을 투명으로 비워두라고 꼭 명시하세요.

### 프롬프트 템플릿

```
[스타일 기준 문장]
횡스크롤 게임 배경의 [중경] 레이어. 가로 1920 세로 360 비율.
```

## 7. 붙일 때

- 캐릭터: 최종적으로 칸 **96×96**, 발바닥이 칸 맨 아래 중앙
- 심통이: 먼지뭉치·고양이 96×96 / 졸린 곰 128×128 / 대왕 160×160
- 표정은 몸 시트와 별도 PNG, 코드가 몸 중심에서 위로 12% 지점에 겹칩니다
- 소품·이펙트·배경 오브젝트는 크기 자유(투명 PNG)
- 마젠타 배경으로 받으셨으면 알려주세요 — 일괄 투명 처리 스크립트 드립니다

## 8. 발주 순서 (이 순서가 제일 안 깨집니다)

1. 주인공 설정화 → 2. 주인공 idle·walk → 3. 간지럼 3행
4. 비눗방울 2행 → 5. 안아주기 3행 → 6. carry 3행
7. 심통이 4종 몸 → 8. 심통이 표정 4칸 → 9. 반응 5행
10. 이펙트 9종 → 11. 소품 4종 → 12. 배경 오브젝트 → 13. 배경 레이어 15장

1~6번만 끝나도 게임 느낌이 완전히 달라집니다. 배경은 마지막에 하세요.
